If it prints tight

Raise SLIDE_CLEAR, THREAD_CLEAR and THREAD_FLANK_GAP by 0.05–0.1 and rebuild; every gap follows. Print one lid and a short body ring first to test.

If it rattles

Lower them in the same steps. The foam takes up axial play, so only radial looseness is felt.

Why "square to the surface"

On a 45° face, a gap measured along the axis is only 0.71 of that square to the face. The thread and pin gaps are set larger along the axis so the true gap stays above 0.3 mm.
